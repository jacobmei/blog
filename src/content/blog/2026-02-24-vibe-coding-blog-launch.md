FOMO 的早不如 FOMO 的好，一切都是最好的安排。

我原本以為我可以完美迴避整個週期的 AI 集體高潮，這幾個月潛心研究密碼龐克的最新進展比較多，我把自己當成超加速主義的抵抗派，結果大過年的，馬上變成還在 vibe coding 隔壁家的叔叔。

原因是喊了兩年的自建部落格每次都因為某種小問題被卡住，而沒有繼續，甚至還雇了朋友手動幫我抓臉書的貼文。結果初六手癢載了 Codex，用嘴巴唸一唸，竟然一個多小時就做完了。

這種多巴胺快速分泌的正回饋太強了。接下來兩三天我的食量變少、睡眠時數降低、連啤酒都不太喝，所以我到今天終於可以理解其他人在嗨什麼。我覺得這段歷程挺珍貴的，因此留一下紀錄。

過年除了家族親戚聚餐之外，大部分的時間都在搬家，吿一段落後，也想逃避成堆的稿債與工作，於是想說找點樂子來玩玩，但傳統的樂子竟然完全被 Vibe Coding 輾過。

我先透過台北書展的 375 大減租（3 本 75 折優惠），買了二十幾本電子書，享受高速切書跳內容閱讀的爽感。但是翻一番後，就跑回去看 webtoon 上面的條漫。

看到無聊了，下載了冰封龐克 2（FrostPunk2），想說很久沒有玩虐心的生存經營類遊戲了。冰封龐克可是實打實的精神時光屋，才不是什麼手遊蓋板廣告寒霜啟示錄。於是我就一邊平衡新倫敦議會的議程，透過忠貞黨員培養秘密黨員，打壓朝聖者，帶領新倫敦市民在地球結凍的時期存活下來。玩到電腦崩潰時，應該是凌晨四點。

但隔天我覺得好累，就不想打開了，而且打開來電腦還是會崩潰。再來是朋友帶來了 PS5，我買了得獎無數的《第 33 號遠征隊》來玩，但是身為遊戲白癡，我在地圖上迷路了一陣，就把 PS5 關了。

然後我就看到了 TonyQ 發文，他說不要再用網頁版的服務了，用了終端機或 Code 版本的軟體會很不一樣，我就想說到底會有多不一樣，結果一打開來真的就沒完沒了了。

我基本上就是用嘴巴一直碎碎念，就把部落格的雛形建好了。後面兩天都是在重構底層設計、修改視覺上的體驗，然後加一堆「無用的」炫砲功能。比如我做了近兩百篇文章的關鍵字與文章的 3D 關聯雲，可以用滑鼠或手指看那精緻的心血結晶，有夠無用。

當甲方的記憶整個回來了，完整走完了資訊採購的流程，甚至補了很多原本懶得學的資訊，真的完全就是「從做中學」。上一次有這麼大的震撼應該是國中打開 Minecraft 的瞬間，同樣也是新世界出現在眼前的感覺。

大概在第三天把 token 用完了（我是本來就有在買 ChatGPT 月費 20 鎂）。心境上大約第三天開始心理比較煩躁，碰到一些講幾句也修不好的內容。不過我馬上檢討自己，一定是自己用詞不精確，所以我就問它要怎麼問，實在是虛心受教。

我也體驗到 GPT-5.3-Codex 的「貼心怪」時刻，我把所有文章都授權 CC BY-NC 時，原本底下的 All Right Reserved 竟然自動改成 Some Right Reserved，我看了痛哭流涕。

由於多巴胺噴發，一周目回饋的時間又極短（嘴完、改完、正式上網站大概三分鐘吧，如果一次開四個對話就不用休息了），所以我嗨到睡前躺在床上也不看漫畫了，就用手機版看看自己的部落格還有哪裡要修，以前值班躺床開 order 都沒有這麼勤勞。

也因此用到上線後，又多課了 40 美金。這筆花費比 webtoon 用金幣看最新話數還要更具有誘惑力。

在慢慢捏出自己喜歡的介面、順流程、堆砌功能的過程中，實在好容易滿足，並且進入心流。

總之做出了一個符合自己風格，自己也很喜歡的部落格，收錄過往自己的文章（剩下臉書還沒打包下載的長廢文），接下來就不怕臉書突然刪我帳號、專欄文章的媒體忽然倒閉、或平台網域被封鎖的情形了。

結果數位自我主權（Self-soverignty）的第一步，竟然是靠 Vibe Coding 做出來的，我實在汗顏，也充滿希望，但也對工程師們表示敬意，我知道我自己的極限在哪裡。

所以新年快樂。有興趣歡迎來看看豆泥的部落格，之後如果有長文也會先在部落格更新與備份。
