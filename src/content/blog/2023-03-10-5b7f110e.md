As I am not an expert in this field, I cannot explain much from a technical standpoint. However, I hope to share some simple information from the user's perspective.

There are currently three common and popular Ordinals wallets:

**Ordinalswallet**

Website: <https://ordinalswallet.com/>

[![](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhdRfNuwSZKVxDc-1xrG44Qd7udvtBf_JCFHQ56vcR4bowpuSZLuq2EKjzcMVpM7lGhYHB68gC01WDnwKjyNsrXOoQaC7owDv8u8w-NOKQvKdJPuVkgz6hAmWDtXfSRBryGyd3mQTemALM9iWVt6JiYDqeQLlivb0WaCumt8A5p_WQ8Jdu8lJhYbTnk/s320/%E6%88%AA%E5%9C%96%202023-03-10%2009.12.15.jpg)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhdRfNuwSZKVxDc-1xrG44Qd7udvtBf_JCFHQ56vcR4bowpuSZLuq2EKjzcMVpM7lGhYHB68gC01WDnwKjyNsrXOoQaC7owDv8u8w-NOKQvKdJPuVkgz6hAmWDtXfSRBryGyd3mQTemALM9iWVt6JiYDqeQLlivb0WaCumt8A5p_WQ8Jdu8lJhYbTnk/s1206/%E6%88%AA%E5%9C%96%202023-03-10%2009.12.15.jpg)

Features: The interface is simple, and it has its own trading platform, making buying and selling easier.

Note: **Currently, there is only a web interface version available and there is no app version or browser extension. When logging in, users need to constantly input "seed phase".  
And use only one address that follows the taproot protocol and starts with "bc1p...", which is used for both BTC and Ordinals.**

**Hiro Wallet**

Website: <https://wallet.hiro.so/>

[![](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEggVpirpLQxgDKUAZ-bXiHH-S4-ewq3eYtlu-mj7Grrp1ePb6bnSZHNTRyHjBYpTf6nQQObcRnKHFRnx3khQ97FcD2ewhdXPgEoDiq0zchQ-87ATSuFSd7M1EPiyVfBXxhHJNOTkJI0sp_KKXc7d2j11s8rdNKFYupCVYAXcgy4wzt9w4x0A02k2JRR/s320/%E6%88%AA%E5%9C%96%202023-03-10%2009.21.12.jpg)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEggVpirpLQxgDKUAZ-bXiHH-S4-ewq3eYtlu-mj7Grrp1ePb6bnSZHNTRyHjBYpTf6nQQObcRnKHFRnx3khQ97FcD2ewhdXPgEoDiq0zchQ-87ATSuFSd7M1EPiyVfBXxhHJNOTkJI0sp_KKXc7d2j11s8rdNKFYupCVYAXcgy4wzt9w4x0A02k2JRR/s830/%E6%88%AA%E5%9C%96%202023-03-10%2009.21.12.jpg)

Features: It supports STX, BTC, Ordinals, and provides stacking services. It is supported by other trading websites such as [Gamma.io](http://Gamma.io). It has a desktop app version and an extension for browsers. **"BTC and Ordinals are separate addresses."**

Note: **Its BTC uses the BIP84 Native-Segwit protocol with a starting prefix of "bc1...", while Ordials follows the taproot protocol with a starting prefix of "bc1p...".**

**Xverse Wallet**

Website: <https://www.xverse.app/>

[![](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEirTmvWMTy7oD61sOtCl1Dv38krLClf6DgAuYGjwfvJyOzoZlELtwZu41iacsSBwzg5DhhpT4xv34orE6DW69exvN__v96KMxiq-YKsd5CyMvUilNEfgWpgF468yzW2G9yVH9ai4H97oaylzW-Hb_0bPJ8MUKGr1vpD-LfLvRFbpb5YbcVK5DQ8APni/s320/6386467d379d6c29f6c89167_Mask%20group-min.png)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEirTmvWMTy7oD61sOtCl1Dv38krLClf6DgAuYGjwfvJyOzoZlELtwZu41iacsSBwzg5DhhpT4xv34orE6DW69exvN__v96KMxiq-YKsd5CyMvUilNEfgWpgF468yzW2G9yVH9ai4H97oaylzW-Hb_0bPJ8MUKGr1vpD-LfLvRFbpb5YbcVK5DQ8APni/s992/6386467d379d6c29f6c89167_Mask%20group-min.png)

  

Features: It supports STX, BTC, Ordinals, and provides stacking services. It is supported by other trading websites such as [Gamma.io](https://gamma.io/ordinals). It has a mobile app version and an extension version for browsers. **"BTC and Ordinals are separate addresses."**

Note: **Its BTC may be following the BIP49 Segwit specification, so the address usually starts with "3..."; while Ordials follows the taproot specification, with addresses starting with "bc1p...".**
