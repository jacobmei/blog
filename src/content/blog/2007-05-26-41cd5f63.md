HemiDemi 黑米網摘網站，最近推出了「[黑米小按鈕](http://www.hemidemi.com/blog/?p=114)」的功能，這段 javascript 語法可以讓部落格站長將語法寫入到版型或是文章中，這樣假如有人收錄這篇文章在黑米網站上，你的部落就會顯示有多少人收藏你的文章，並有多少人討論你的文章。  
  
這是一種很方便的跨網路社群模式，之前 CK 寫了兩個外掛模組  
[HEMiDEMi Scriptlet - 誰在背後講我?](http://flickr.tw/2006/08/hemidemi_scriptlet_1.html)  
[HEMiDEMi Scriptlet - 誰收藏本文?](http://flickr.tw/2006/08/hemidemi_scriptlet.html)  
都是類似的工具，CK 寫的還包括了大頭貼的顯示，看起來非常有趣，而黑米自家的則是非常清爽，將收藏和討論的數字一併顯示，大家可以依照需要各取所需。  
  
小梅子的 Blog 架設在 Google 的 Blogger 平台上，它的樣板稍微複雜一點，小梅子想或許也有別人想知道怎麼將黑米小按鈕放在 Blogger 上面，所以有這篇簡易教學。  
  
先看看不同的位置效果。  
  
[![](/src/content/blog/assets/blogger/blogger-41cd5f63-hemidemi_m.jpg)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjunrDFSMxnPnhx24IslUYMmZE6BWjV8Z9UCvbnDhcumYWAL2_K2MwHjnFLdQzowx24MZlFo6Ao96zANJAkkRGldA-MGDqLoG1MZ-8rXTQjgnqjCZQiGbgJHc65MYsa_1eh3aHmYzSDyXI/s1600-h/hemidemi_m.jpg)這是將黑米小按鈕放在每一篇文章的結尾，回應的前面，[黑米小按鈕](http://www.hemidemi.com/blog/?p=114)的語法請直接取用，問題是這個要放在 Blogger 板型的哪裡。  
  
要搞懂這個，請先了解目前 Blogger 的板型模式有分新版和舊板兩種，小梅子這邊的教學是針對新版的，假如你還在舊板的 Blogger，請自行先升級到新版，新版的好處多了不少，包括了 Tag 等的使用，會更靈活。  
  
但老實說，新板的要修改板型也更難一些。  
  
[![](/src/content/blog/assets/blogger/blogger-41cd5f63-hemidemi_s.jpg)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjHRF0I9arffo9L2b601jZfMwquvDNYu2e3uSxw5Ll56WqaYmJQzmWGp-Dq-67VQxdk5OL4tatnyErj2WzLwTGjqiM1a3HuCRLkgQ1y8YMQNbVmjqLuQVwog_h4QuQ_tzE2T1CvMz-EBlE/s1600-h/hemidemi_s.jpg)在登錄了 Blogger 後台以後，請找到【範本】下的【修改 HTML】的選項。  
  
這裡請注意，這邊有一個【在編輯模版之前，您可以先儲存一份模版。 下載完整模版】的功能，請務必下載一份你現有的板型備份，這樣假如不幸手賤搞砸了，還可以完整回復先前的設計。  
  
然後右方有一個【展開小裝置範本】的選項，請打勾，這樣下方的板型模組碼，才會完整的顯示出來。  
  
接下來的動作要頭腦清晰點 :P  
  
請在這一串板型模組碼中，找到  
<b:includable id='comments' var='post'>  
這一句，然後將黑米小按鈕的語法放在後面。  
  
整體看起來就會像是這樣：  
  
<b:includable id='comments' var='post'>  
<script type="text/javascript">  
HEMiDEMi\_Bookmark\_Button\_Style = 'button1';  
</script>  
<script src="http://js.hemidemi.com/javascripts/hemidemi\_bookmark\_button.js" type="text/javascript"></script>  
  
點一下右下角的【儲存範本】，就可以收工看一下顯示的效果如何。  
  
[![](/src/content/blog/assets/blogger/blogger-41cd5f63-hemidemi_b.jpg)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEj0uACvNMNonya3EoLDjlDIadItqV6IjFF8Q4-cKxEINDmBkq95B8mrq3O2NANQDxBon1uUXZSIT9nYT-Q99-DUp2wr458LRsALRvP3iGCI7sz3SkU_9SMAwVArjmuedTJC0DDGGo5ShLs/s1600-h/hemidemi_b.jpg)另外一個可以擺放的位置，是在文章回應的下方，再置放黑米小按鈕，這邊順便推薦一下 CK 寫的[HEMiDEMi Scriptlet - 誰在背後講我?](http://flickr.tw/2006/08/hemidemi_scriptlet_1.html)的黑米外掛語法，這樣就可以同步將黑米上面別人討論你的文章，也直接顯示在同一個頁面下，你就不用到處觀看，深怕哪邊忘了回應。  
  
類似剛剛上面的做法，同樣，我們要在板型模組碼中，找一個叫  
  
<b:if cond='data:blog.pageType == "item"'>   
的語法，然後將黑米小按鈕，甚至 CK 寫的誰在背後說我兩組小語法都放在這個後面。  
  
整體看起來就會像是這樣：  
  
<b:if cond='data:blog.pageType == "item"'>  
<script type="text/javascript">  
HEMiDEMi\_Bookmark\_Button\_Style = 'button1';  
</script>  
<script src="http://js.hemidemi.com/javascripts/hemidemi\_bookmark\_button.js" type="text/javascript"></script>  
<script src='http://webdev.yuan.cc/scriptlets/hemidemi\_comments.js'>  
</script>  
  
這樣你就會得到雙效合一的顯示效果了 :-)
