自從用了 OS X 以後，其實真的沒有花什麼錢買軟體了，因為上面有許多很棒的免費軟體資源可以取得，而且大多都有中文界面，從文書軟體、影像處理軟體到網頁製作軟體都有，小梅子和大家分享一下自己常用，並值得推薦的 Mac OSX 免費軟體。  
  
假如大家有時間想要多玩一些軟體，可以去老牌軟體介紹網站 [Versiontracker](http://www.versiontracker.com/macosx/) 自己試看看 :-)  
  
小梅子本次從綜合性文書處理軟體介紹起。  
  
綜合性文書處理軟體：[NeoOffice](http://www.neooffice.org/)  
[![](/src/content/blog/assets/blogger/blogger-b6def315-osx_neooffice.jpg)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEgar9WlTfgIqh209Sht92MhqcSyWGQhxwprfICndXdviieErDmoZHIXk5hdn2grwRVeaEMg_SaJkl-EfCH-WGf_Gz2vCNv1qnQs4IgzmVRMkuia7IjpXadEz957kKmZ6GgfcFgVdPDlEpo/s1600-h/osx_neooffice.jpg)  
  
這是移植 [OpenOffice](http://www.openoffice.org/) 到 OSX 上面最成功的軟體之一，說它成功，是因為它以 Java 為核心重新編寫了 OpenOffice，完全不用 X Windows 的環境就可以直接執行，而且速度還不錯。  
  
NeoOffice 是一套完整的辦公室軟體環境，包括了文書處理、試算表、簡報軟體三大主類，完全支援微軟架構的 MS Office 檔案格式，並且支援 Office 2007 文件格式和 macro 聚集指令，也有完整中文界面包可以下載，是一個超棒的軟體。  
  
另外 NeoOffice 也有資料庫的功能，中文也相容喔，假如你用蘋果電腦，又不想要花錢買[FileMaker](http://www.filemaker.com.tw/)的話，可以試試 NeoOffice 的這部份功能。  
  
同場加映：[OpenOffice.org Aqua for Mac OSX](http://porting.openoffice.org/mac/download/aqua.html)  
[![](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhDFfKtUXaNLdqKrXpNX2xoqqb1YOb2T_ugP1qoSrP21kiqlqGLuFB85yyOYzw_aiA2prgk_ebBHwRLX40S49BM4AfXRTLFegQYoc_k1i2PkV3KiJsxGh3C6S2GvigMZ0MleNyMMIY8niw/s320/%E5%9C%96%E7%89%87-1.jpg)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhDFfKtUXaNLdqKrXpNX2xoqqb1YOb2T_ugP1qoSrP21kiqlqGLuFB85yyOYzw_aiA2prgk_ebBHwRLX40S49BM4AfXRTLFegQYoc_k1i2PkV3KiJsxGh3C6S2GvigMZ0MleNyMMIY8niw/s1600-h/%E5%9C%96%E7%89%87-1.jpg)  
  
其實[OpenOffice](http://www.openoffice.org/)在今年也推出了Aqua版的 [OpenOffice.org Aqua for Mac OSX](http://porting.openoffice.org/mac/download/aqua.html)，Aqua版的也不需要透過 X Windows 的環境就可以直接執行，而且小梅子測試過它和 NeoOffice 兩套的速度，OpenOffice.org Aqua for Mac OSX 的整體執行速度還比 NeoOffice 快一點點 :-)  
  
不過因為 NeoOffice 一直都很積極且熱心的移植 Java 版本，所以小梅子情感上會比較支持 NeoOffice XD  
  
同場加映：[Google 線上文件](http://docs.google.com)  
[![](/src/content/blog/assets/blogger/blogger-b6def315-google_docs.jpg)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhABu-ff-0Bxiqj3nC6x7vcTN5mMGEnz9hUywkTsFBb8B8_Hb7rXFg71tjWQOZPJ5IxoHKxNuGa5cMnv7lAvuT2mGGA-LwDzVjoyxgJYbXIKPFxbUegxn6KCIUvMiMDfRVYyoHkEzTK3Gw/s1600-h/google_docs.jpg)  
  
小梅子曾經以為 Google 線上文件讓我可以不用在電腦中再安裝這些辦公室軟件了，不過，一方面由於文件的支援度還不如上述兩個軟體好，並且，因為檔案需要先上傳到 Google ，所以檔案大小也有限制：  
> 文件 (最大 500KB)  
> HTML 檔案和純文字 (.txt)。  
> Microsoft Word (.doc)、Rich Text (.rtf)、OpenDocument Text (.odt) 與 StarOffice (.sxw)。  
> 簡報 (從您電腦上載的上限為 10MB，從網路上載的上限為 2MB，透過電子郵件上載的上限為 500KB)  
> Microsoft PowerPoint (.ppt, .pps)。  
> 試算表 (最大 1MB)  
> 逗號分隔值 (.csv)。  
> Microsoft Excel (.xls) 檔案和 OpenDocument Spreadsheet (.ods)。  
> PDF 檔案 (最多 10MB 來自您的電腦，2MB 來自網頁)

  
  
所以目前只能當做臨時性使用，還無法替代完整的公視文書軟體套件。當然網路上還有其他的優秀線上軟體工具可以使用，不過小梅子個人還是比較願意壓寶在這個有點殘缺的 Google Docs 上面 XD
