## 第一章　總則

### 第一條

| | 條文內容 |
|---|---------|
| **原文** | 本堂定名為財團法人**台灣省**台北市中國基督教靈糧世界佈道會台北靈糧堂（以下簡稱本堂）。 |
| **修正後** | 本堂定名為財團法人台北市中國基督教靈糧世界佈道會台北靈糧堂（以下簡稱本堂）。 |

> ✏️ **修正說明**：刪去「台灣省」，法人名稱精簡為「台北市」層級。

---

### 第二條

| | 條文內容 |
|---|---------|
| **原文** | 本堂基本信仰為：信聖父、聖子、聖靈為三位一體之真神，信全部聖經是神所默示的，信主耶穌道成肉身，為童貞女從聖靈懷孕而生，死在十字架上，第三天復活，以後升天，不久還要再來，信人得救，惟一方法是以信心接受耶穌基督為救主，從聖靈重生成為神的兒女。 |
| **修正後** | 同上（未修正）。 |

---

### 第三條

| | 條文內容 |
|---|---------|
| **原文** | 本堂宗旨為：「往普天下去傳福音給萬民聽」（馬可福音十六章十五節）並建立教會。 |
| **修正後** | 同上（未修正）。 |

---

### 第四條

| | 條文內容 |
|---|---------|
| **原文** | 本堂主要工作為：傳道、出版、慈善、教育等。 |
| **修正後** | 同上（未修正）。 |

---

### 第五條

| | 條文內容 |
|---|---------|
| **原文** | 本堂堂址設於台北市和平東路二段廿四號**至**廿六號。 |
| **修正後** | 本堂堂址設於台北市和平東路二段廿四號、廿六號、**廿八號**。 |

> ✏️ **修正說明**：堂址由「廿四號至廿六號」改為明確列舉三個門牌號，並增加廿八號。

---

## 第二章　組織

### 第六條

| | 條文內容 |
|---|---------|
| **原文** | 本堂設董事會由董事**三**人組織之，除由中國基督教靈糧世界佈道會會長即創辦人為當然董事外，餘**二**人由本堂執事中選任之。 |
| **修正後** | 本堂設董事會由董事**五**人組織之，除由中國基督教靈糧世界佈道會會長即創辦人為當然董事外，餘**四**人由本堂執事中選任之。 |

> ✏️ **修正說明**：董事人數由三人增加為五人，選任董事由二人增加為四人。

---

### 第七條

| | 條文內容 |
|---|---------|
| **原文** | 本堂董事會設董事長一人，由董事互選之。 |
| **修正後** | 同上（未修正）。 |

---

### 第八條

| | 條文內容 |
|---|---------|
| **原文** | 本堂董事之任期為三年，期滿得連選連任，如有左列情形之一者，應即另選繼任：一、死亡；二、遷移其他教區者。前項補缺之董事以補足前任董事任期為期。 |
| **修正後** | 同上（未修正）。 |

---

## 第三章　會議

### 第九條

| | 條文內容 |
|---|---------|
| **原文** | 本堂董事會定**每三個月**開會一次，由董事長召集之，必要時得召集臨時會議。 |
| **修正後** | 本堂董事會**每一年**開會一次，由董事長召集之，必要時得召集臨時會議。 |

> ✏️ **修正說明**：董事會開會頻率由每季（三個月一次）改為每年一次。

---

### 第十條

| | 條文內容 |
|---|---------|
| **原文** | 董事會開會須有董事過半數之出席方能開會，議決事項以出席者過半數之同意行之。 |
| **修正後** | 同上（未修正）。 |

---

## 第四章　財務

### 第十一條

| | 條文內容 |
|---|---------|
| **原文** | 本堂之資產及經濟來源如下：（一）依據土地法業經登記為本堂之產權及其他信徒奉獻或購入尚未依法登記取得產權之一切房地不動產等；（二）信徒捐獻之現款及財物等；（三）本堂舉辦事工（即公益事業）及財產方面之收益等。 |
| **修正後** | 同上（未修正）。 |

---

### 第十二條

| | 條文內容 |
|---|---------|
| **原文** | 本堂所有財產除聖堂外，如有增購或移轉之處分，應限於本章程第四條規定各項工作之需要為原則，並須經董事會議決通過。 |
| **修正後** | 同上（未修正）。 |

---

### 第十三條

| | 條文內容 |
|---|---------|
| **原文** | 本堂會計年度以每年一月一日起至同年十二月三十一日止為會計年度。 |
| **修正後** | 同上（未修正）。 |

---

## 第五章　附則

### 第十四條

| | 條文內容 |
|---|---------|
| **原文** | 本堂設執事會，辦事細則另訂之。 |
| **修正後** | 本堂設執事會，**秉承董事會處理本堂一切聖工**，其辦事細則另訂之。 |

> ✏️ **修正說明**：明確增列執事會職責，強調其「秉承董事會」之從屬關係及「處理本堂一切聖工」之職能範圍。
