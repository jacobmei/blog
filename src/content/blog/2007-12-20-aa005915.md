在幾個月之前，Nokia 推出了[行動搶頭香](http://www.blogpush.tw/push/)的手機服務，光看這個名詞，實在很想到這個服務是什麼東西，講的白話一點呢，這個服務其實就是「手機 RSS 訂閱」服務啦。  
  
講起手機訂閱 RSS，其實不是很新奇的技術，網路上有很多類似的服務機制，有些是平台業者自己推出的，有些是軟體廠商提供的，Google code 上面也有免費的[手機 Java 版本的 Ree reader](http://code.google.com/p/mobile-rss-reader/)可以使用，有些手機商更直接將相關軟體直接附在手機中，所以當小梅子第一次聽到這個服務機制的時候，還實在不知道 Nokia 要怎麼推這個好像不是很新潮的東西 :P  
  
不過當看到說明後，小梅子馬上露出了欣喜笑容，因為，Nokia 雖然比較慢進入市場，但也是類似產品中，相對使用障礙最低的機制 :-)  
  
首先，小梅子簡單解釋一下現在大多數的 RSS 服務機制會有的問題：  
  
a. 需要專屬的軟體（通常是 Java 版）：但目前手機型號（主要是手機用的系統）很多種，所以也不是一個軟體下載後就可以適用所有手機，比較好的服務還會告訴你要怎麼選用合適手機型號的軟體，不然你就得自己下載後自己測試 XD  
  
b. 有些手機版的服務只能看到文字檔，不會有圖片顯示，就算有圖片顯示，因為牽涉到網路傳輸流量的問題，所以圖越大越多，使用者得花的傳輸費也越高。  
  
c. 相關的設定滿複雜的，不容易使用。  
  
不過這些都還不是最大的盲點，最大的盲點在於：  
  
使用者倒底為什麼要自己額外花錢來用這個服務？真的有什麼得必須馬上看的資訊嗎？  
  
這個盲點沒有想清楚，相關的服務就會一直很難真正的被推動。  
  
回頭來看看 Nokia 這次推動的機制流程 :-)  
  
Nokia 的[行動搶頭香](http://www.blogpush.tw/push/)在機制上捨棄了「獨門軟體下載使用」的方式，直接透過 MMS 簡訊的傳統使用方式，將你訂閱的 RSS 內容，連圖帶文的一篇篇送上。  
  
這麼做的好處在哪裡？它解決（或說避重就輕 XD）了其他服務商會面對的三個問題：  
  
a. MMS 多媒體簡訊開通的設定方式，相較其他服務更為簡單，並且現在幾乎每隻手機都會支援接收 MMS 簡訊的功能，省去了不同手機、平台業者之間的障礙。  
  
b. [行動搶頭香](http://www.blogpush.tw/push/)的使用計價方式，為每則2元，包含圖文都可以看到。  
  
c. 平台業者（例如中華電信等）大都會提供懶人法 MMS 設定方式，透過適當的教學，開通成功率超高。  
  
因為使用的是 MMS，所以額外的好處包括了：  
  
下載後可以隨時再讀取，不用再次連線網路，比較省錢和省時間；另外，MMS 中的圖片也可以被擷取出來另外存檔 :P  
  
不過 Nokia 還是得面對：使用者倒底為什麼要自己額外花錢來用這個服務？真的有什麼得必須馬上看的資訊嗎？  
  
目前 Nokia 想出的推廣方向還是不離「你喜歡這個部落嗎？喜歡的話就訂閱手機行動搶頭香服務吧」，問題是，一則 MMS 簡訊要兩元，假如我多訂閱了幾個熱門寫手的部落，一個月大概得要好幾百元，這樣的使用行為，可能又不如手機網路吃到飽的方案划算，整個服務就很難推啊。  
  
觀於推廣，小梅子倒是有一個建議方向。  
  
這類的服務機制，最基本的策略，還是「提供的資訊夠不夠吸引人」，這裡的吸引，不是指內容深度，而是「好康」，講的更白話一些，就是 coupon 啦。  
  
所以我建議 Nokia 可以改變一下推廣的模式，直接朝商業大步邁進，整個概念是這樣：  
  
商家付費推 coupon，網友免費玩 MMS  
  
例如當網友想要訂閱[艾瑪](http://blog.pixnet.net/amarylliss)或是[酪梨壽司](http://blog.pixnet.net/cwyuni) 的部落文章，本來一則MMS 簡訊要2元，現在就由某漢堡業者提供贊助，條件是訂閱的網友也會收到該漢堡業者的 MMS coupon 簡訊，而網友憑 MMS 簡訊上的 coupon 圖片，就可以消費有好康 :-)  
  
這是一個簡單的多贏模式。  
  
對於格主而言，這樣的贊助完全不會影響原本部落的寫作內容，也不用在部落上掛廣告宣傳，但是可以讓更多的網友訂閱自己的部落，也增加更多的閱讀者。  
  
對於網友而言，可以第一時間免費收到最新的 RSS 訂閱，又可以得到隨身帶的 Coupon，可以存檔隨時使用，非常方便，又完全不用花錢。  
  
對於合作業者，這樣的行銷非常直接，比發傳單和 edm 的成本要低，而 coupon 又可以讓使用者自行傳遞轉寄，是很有效的病毒行銷。  
  
對於 Nokia 等，越多商家業者加入，越多使用者免費使用，這個服務的推廣就會如等比效應般的擴散出去。  
  
小梅子這裡用了一個比較簡單的模式來說明這個想法，其他手機服務最類似的對比，大概就是 QR Code 了，不過 QR Code 有更麻煩的手機硬體、系統業者、參與商家、使用者習性等門檻要跨過，相較之下，Nokia 的[行動搶頭香](http://www.blogpush.tw/push/)回歸到「基本」，若配以更好的行銷推廣概念，真正抓住使用者的心，或許是一個很棒的殺手級應用。
