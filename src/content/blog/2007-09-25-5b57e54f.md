[![](/src/content/blog/assets/blogger/blogger-5b57e54f-lightbox.jpg)](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjdpXD-yzTZHGYzq52cty_3UFU00-ehv2A_mX5W15VTDZN3oWmPpBN-Z6fWBgPUVZVcZPIm8Wo-oAMHCQwJwMgba2-V7UIotDb7XwGs8UFt1-dy7bkoH_xXbIbWgEBKhgno5XgJQKMIEjc/s1600-h/lightbox.jpg)小梅子自己是[Flickr 相簿](http://www.flickr.com/photos/macdog/)的使用者，也是 [Google Picasa 相簿](http://jacobmei.blogspot.com/2007/03/1gb-picasa.html)的愛好者，不過呢，我自己還是搞了一個有簡易燈箱效果的 [小梅子網路相簿](http://www.jacobmei.com/photos/)，這真是無聊又白爛的行為啊。  
  
這個網路相簿用的是簡單的 javascript 語法和 php 語法，配合一些 css 的設計，讓畫面看起來很簡潔，我個人喜歡這種簡單呈現的東西啦。  
  
今天有網友 smile.jocat 問起這個相簿是怎麼做出來的，所以我就將我用到的網路資源提供給大家一起參考。  
  
1. [MOSAIC MINI](http://mosaic.yellowgreen.de/)  
這是一個很酷的小巧燈箱像簿，可以自動產生不同格式大小的相簿呈現，只要將相片上傳到同一個檔案夾就可以了，堪稱是最簡易的自動化一步到位的網路相簿。  
不過這需要主機支援 php 的語法，而且它沒有換圖的功能。  
  
2. [Lightbox2](http://www.huddletogether.com/projects/lightbox2/)  
這是超酷的燈箱語法，很多網站都是以這個為核心改良成自己用的版本，純 javascript ，相容性極高，有換圖的功能。  
  
所以小梅子就將這兩個語法合併在一起，拼湊一下，就是各位現在看到的 [小梅子網路相簿](http://www.jacobmei.com/photos/)了 :-)
